# patches/

Client patches for this pack (experimental): `<module>.patchset.toml` byte
patches, usually `game.exe.patchset.toml`, and native plugin DLLs listed in
`pack.json` under `patches.plugins`.

Delete this folder if your pack doesn't patch the game. The format and how
patches are applied: [docs/client-patches.md](../../../docs/client-patches.md).
